# Pass 5: Narrative & Historical Review Protocol

## 목적

Pass 5는 맞춤법이나 표기 교정이 아니라 작품의 내용적 신뢰도와 소설성을 검수한다. 외부 에이전트는 원고를 직접 수정하지 않고 문제 제안만 남긴다. 최종 수정 권한은 편집 루프에만 있다.

## 핵심 원칙

1. **검수와 수정 분리**: 검수자는 원고 파일을 수정하지 않는다.
2. **독립 판단 우선**: 다른 검수자의 결론을 읽기 전에 자신의 보고서를 작성한다.
3. **근거 없는 취향 배제**: 모든 지적에는 원문 위치와 이유가 필요하다.
4. **중복은 신뢰도 신호**: 서로 독립적인 검수자가 같은 문제를 잡으면 우선순위를 높인다.
5. **최종 편집 단일화**: 채택된 지적만 별도 수정 커밋으로 반영한다.
6. **회귀 검수**: 수정 뒤에는 앞뒤 장의 연속성과 새 오류 유입 여부를 다시 확인한다.

## 권장 검수 역할

- `historian`: 연대, 사건, 기술, 당시 지식 수준, 역사적 사실성
- `continuity`: 시간선, 위치, 인물 지식, 소유물, 관계, 사건 인과
- `character`: 욕망, 동기, 말투, 감정 변화, 행동 일관성
- `novel-editor`: 장면 기능, 긴장, 설명 과잉, 정보 전달용 대사, 반복
- `blind-reader`: 원고만 읽는 초독자 관점의 이해 가능성
- `red-team`: 출판 후 혹평 가능성, 편향, 억지 전개, 취약한 주장

## 표준 루프

1. `11_REVIEW/QUEUE.md`에서 대상 장을 선택한다.
2. 검수자는 해당 장과 자신의 역할에 필요한 자료만 읽는다.
3. 결과를 `11_REVIEW/inbox/<role>/` 규칙에 맞춰 작성한다.
4. 원고 파일은 수정하지 않는다.
5. 편집 루프가 inbox 결과를 모아 중복·충돌·근거를 검토한다.
6. 결정은 `11_REVIEW/decisions/`에 기록한다.
7. `accepted`만 원고 수정 후보가 된다.
8. 수정 후 해당 장과 인접 장을 회귀 검수한다.
9. 모든 치명·중대 항목이 닫히면 해당 장을 `reviewed`로 표시한다.

## 심각도

- `CRITICAL`: 연대 역전, 핵심 사실 오류, 인물/사건의 명백한 자기모순
- `MAJOR`: 독자의 이해나 개연성을 크게 해치는 문제
- `MINOR`: 읽기 흐름, 반복, 설명 밀도 등 국소 문제
- `NOTE`: 수정이 필수는 아니지만 편집자가 고려할 제안

## 판정 상태

- `OPEN`: 아직 판단 전
- `ACCEPTED`: 수정 필요
- `REJECTED`: 근거 부족, 의도된 표현, 오탐
- `DUPLICATE`: 다른 항목과 동일
- `DEFERRED`: 이번 판에서 수정하지 않음
- `FIXED`: 수정 반영 및 회귀 검수 완료

## 종료 조건

Pass 5는 다음을 모두 만족해야 종료한다.

- 48장 모두 최소 2개 이상의 서로 다른 역할이 검수
- `CRITICAL` 미해결 0건
- `MAJOR` 미해결 0건 또는 편집상 명시적 `DEFERRED`
- 채택된 수정의 회귀 검수 완료
- 최종 내용 검수 보고서 작성

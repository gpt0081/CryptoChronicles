# Pass 5 Character Art Audit

## Scope

Publication-readiness audit for the six canonical protocol/asset portraits referenced by `02_CHARACTERS/CAST_INDEX.md`.

## Result

**PASS — six legacy JPG placeholders replaced by a unified SVG character set.**

| Character | Canon file | Recognition anchor | Real-person likeness risk | Status |
|---|---|---|---|---|
| Bitcoin | `portraits/bitcoin.svg` | heavy pioneer silhouette, worn-metal geometry | none intended | PASS |
| Ethereum | `portraits/ethereum.svg` | layered architectural geometry, blueprint network | Vitalik likeness explicitly avoided | PASS |
| XRP | `portraits/xrp.svg` | crossing corridors, formal mediator silhouette | Ripple staff likeness avoided | PASS |

## Consistency check

- All six use the same `800×1000` 4:5 canvas.
- All six are deliberately non-photorealistic vector characters.
- Faces are simplified graphic masks rather than attempts to depict real founders.
- Identity comes from silhouette, posture, geometry, props, and network environment rather than pasted logos.
- The palette varies by role while line weight, framing, and bust scale remain within one visual system.
- `Satoshi Nakamoto` remains without a canonical face.
- Hal Finney and Vitalik Buterin remain historical human dossiers, not protocol portraits.

## Link audit

`CAST_INDEX.md` now references only the six SVG files. The previous JPG placeholders were removed, so there is no ambiguous second portrait set in `02_CHARACTERS/portraits/`.

## Publication-readiness impact

The character-art replacement condition is **closed**. Future art changes are optional art-direction revisions unless they introduce a broken link, real-person misrepresentation, or contradiction with `CHARACTER_ART_BIBLE.md`.

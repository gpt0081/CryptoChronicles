# TERMINOLOGY

| 용어 | 소설적 번역 | 정확성 주의 |
|---|---|---|
| Blockchain | 공동 장부 / 도시의 기록망 | 모든 블록체인이 동일 구조는 아님 |
| Node | 장부 보관자 | 합의 역할은 네트워크마다 다름 |
| Mining | 블록 봉인 경쟁 | PoW에 한정 |
| Staking | 담보를 건 검증 참여 | 네트워크별 구조 차이 |
| Smart Contract | 자동 집행 계약 기계 | 법적 계약과 동일하지 않을 수 있음 |
| Oracle | 외부 정보망 | 단일 정보원이 아님 |
| Bridge | 체인 간 교량 | 설계마다 보안 모델이 다름 |
| Stablecoin | 기준가치 유지 화폐 | 담보 구조별 위험이 크게 다름 |
| L1 | 독립 기반 도시 | 정의의 경계가 프로젝트마다 다를 수 있음 |
| L2 | 상위 체인에 기대는 확장 구역 | 보안·데이터 가용성 구조 구분 필요 |

# CANON RULES

## Canon 등급

- **C0 — 검증 사실**: 복수의 신뢰 가능한 출처 또는 1차 자료로 확인.
- **C1 — 강한 해석**: 사실에 근거한 해석이지만 단일한 정답은 아님.
- **C2 — 소설적 각색**: 대화·심리·장면·상징 등 창작 요소.
- **C3 — 가설/미확정**: 조사 중. 본문 확정본에 사용 금지.

## 실제 발언 규칙

따옴표로 실제 발언을 재현하려면 출처를 확보한다. 출처 없는 대사는 모두 의인화된 캐릭터의 창작 대사로 취급한다.

## 역사 변경 금지

실제 사건의 승패·날짜·프로토콜 분기·파산·해킹·규제 결과를 극적 편의를 위해 바꾸지 않는다. 필요한 경우 장면을 압축하되 `FACT_CHECK.md`에 기록한다.

## 현재성 규칙

제4부의 최근 사건은 집필 직전 웹에서 다시 검증한다. 저장된 연표가 최신이라는 가정을 하지 않는다.

# CryptoChronicles

암호화폐의 실제 역사를 바탕으로, 네트워크·자산·기업·제도를 개성과 욕망을 지닌 행위자로 의인화해 재구성하는 4부작 장편소설 프로젝트.

## 핵심 원칙

- 실제 역사적 사건의 날짜·순서·결과는 검증한다.
- 실제 인물과 의인화된 코인/네트워크는 분리한다.
- 창작 대사는 실제 발언처럼 인용하지 않는다.
- 가격은 서사의 주인공이 아니라 사건의 결과로 다룬다.
- `00_MASTER/`와 `08_CONTINUITY/`를 작품의 정본(canon)으로 본다.

## 4부작 임시 구성

1. **제1부 — Genesis**: 2008~2013, 금융위기와 비트코인의 탄생
2. **제2부 — The Programmable City**: 2014~2017, 이더리움과 프로그램 가능한 경제
3. **제3부 — The Age of Leverage**: 2018~2022, DeFi·NFT·스테이블코인·레버리지와 붕괴
4. **제4부 — The Return of Empire**: 2023~현재, ETF·기관·정부·RWA와 제도권 편입

## 집필 순서

`역사 조사 → Fact Ledger → 장면 설계 → 초고 → 캐릭터 검사 → 연속성 검사 → 사실 검증 → 정본 반영`

# Volume 2 End State — 2017

## 주요 인물 상태

| 인물 | 2부 종료 상태 | 핵심 학습 | 3부 진입 조건 |
|---|---|---|---|
| Bitcoin | 원로 혁명가. Mt. Gox 붕괴와 scaling war를 거치며 ‘프로토콜과 인간 조직은 다르다’는 입장이 더욱 강해짐 | 어떤 기업·채굴자·개발자·노드도 혼자 Bitcoin을 결정할 수 없음 | 2018 겨울에서 가격 붕괴와 생존을 견딤 |

| Code | 더 이상 ‘법’ 그 자체로 단순화할 수 없는 존재 | 의도는 실행하지 않고 명령만 실행함 | DeFi 시대 스마트컨트랙트 리스크의 핵심 원리로 재등장 |
| The DAO | 역사적 실험으로 붕괴·종료 | 탈중앙 조직의 가능성과 스마트컨트랙트 취약성, 거버넌스 문제를 동시에 남김 | 직접 주역은 퇴장하지만 DAO·DeFi 거버넌스의 조상처럼 기억됨 |

| 국가/SEC | 기술 자체보다 경제적 실질과 투자자 보호 문제를 보기 시작 | 토큰이라는 이름만으로 기존 법이 자동 무효화되지는 않음 | 3~4부 규제 세력의 전초가 됨 |
| 가격 | 2017년 극단적 과열과 급락을 경험 | 프로토콜 가치와 시장의 기대는 별개의 층 | 2018년 겨울에서 다시 냉혹한 선별자가 됨 |
| 신용 | ICO 열풍에서 ‘미래를 당겨 파는’ 구조가 암호화폐 안에도 재현됨을 확인 | 탈중앙화가 신용·레버리지를 제거하지 않음 | DeFi 대출, yield, stablecoin, 2022 연쇄붕괴의 핵심 원리로 복귀 |

## 관계 변화
- Bitcoin ↔ Ethereum: `존중 + 경계`에서 `서로의 실패를 이해하는 경쟁자`로 변화.
- Ethereum ↔ Ethereum Classic: 같은 과거를 공유하지만 DAO fork에 대한 정반대의 기억을 선택한 분기 관계.
- Bitcoin ↔ Bitcoin Cash: 같은 UTXO 역사에서 갈라진 scaling 철학 경쟁.
- Ethereum ↔ Code: ‘코드가 답’이라는 순진한 신뢰에서 ‘코드는 판단하지 않는다’는 성숙한 관계로 변화.
- Ethereum ↔ 국가/SEC: 외부 규제를 낡은 체제라고만 보던 태도에서, 투자자·법적 실질 문제를 무시할 수 없다는 긴장된 대화로 변화.
- Ethereum ↔ ICO: 자신의 범용성이 낳은 자랑스러운 자식이자 통제 불가능한 위험.

## 2부 종료 장면의 정서
2017년 연말. Bitcoin과 Ethereum 모두 가격상으로는 승리자처럼 보이지만 내부적으로는 더 회의적이고 성숙해졌다. 눈이 내리기 시작하며 `The Age of Leverage`의 2018년 겨울로 넘어간다.

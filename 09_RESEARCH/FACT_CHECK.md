# FACT CHECK

## Volume 1 / Chapter 01 — 신뢰가 멈춘 날

### 역사 사실
- [x] 날짜 확인: Lehman Brothers 파산 신청 2008-09-15
- [x] 사건 순서 확인: Lehman 파산 신청 후 2008-09-16 AIG 긴급 신용공여 승인
- [x] 금액·수량 확인: AIG 신용공여 한도 최대 850억 달러
- [x] 기술 메커니즘 확인: 금융기관·단기자금시장 신뢰 위기는 공식 연준 회고 자료와 일치하는 수준으로만 서술
- [x] 관련 조직/인물 역할 확인

### 인용
- [x] 본문에는 실제 인물의 직접 인용문을 사용하지 않음
- [x] 리먼·연준·AIG·신용의 모든 대사는 C2 의인화된 창작 대사임
- [x] 실제 기관이 해당 문장을 발언했다는 인상을 주는 인용 표기는 사용하지 않음

### 인과관계
- [x] Bitcoin 탄생이 금융위기 하나 때문에 일어났다고 역사적 사실로 단정하지 않음
- [x] 금융위기와 작품의 중심 질문 사이 연결은 서사적·해석적 장치로 처리
- [x] AIG 지원의 판단 이유는 시스템 위험이라는 공식 자료와 모순되지 않음

### 연속성
- [x] Bitcoin은 아직 실체가 없는 ‘태어나기 전 인물’로만 묘사됨
- [x] 2장 예정 사건인 2008-10-31 백서 공개를 선취해 실제 발생한 것처럼 쓰지 않음
- [x] 회사와 토큰/프로토콜을 혼동하는 문제 없음
- [x] 브루클린 공장주와 퀸스 부부는 합성 허구 인물임을 Fact Ledger에 기록

### 주요 출처
1. Federal Reserve History, `Support for Specific Institutions` — Lehman의 2008-09-15 파산 신청과 AIG 지원의 사건 순서.
   https://www.federalreservehistory.org/essays/support-for-specific-institutions
2. Federal Reserve Bank of New York, `Actions Related to AIG` — 2008-09-16 최대 850억 달러 신용공여 승인.
   https://www.newyorkfed.org/aboutthefed/aig
3. Federal Reserve Bank of New York, `Some Observations and Lessons from the Crisis` — Lehman 이후 금융 패닉과 신뢰 붕괴에 대한 회고.
   https://www.newyorkfed.org/newsevents/speeches/2010/pot100607

### 결과
- 상태: **VERIFIED — 정본 편입 가능**
- 발견된 오류: 없음. 단, ‘금융위기가 Bitcoin을 직접 낳았다’는 단선적 인과로 읽히지 않도록 이후 장에서도 주의한다.
- 수정 내역: 회사·기관 대사를 역사적 인용이 아닌 C2 의인화로 명시하고, 합성 허구 인물의 범위를 Fact Ledger에 기록했다.

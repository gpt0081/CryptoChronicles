# Hal Finney

## 역할
Bitcoin 초창기의 실제 참여자. 작품에서는 초기 네트워크가 한 사람의 발명에서 실제 사용자 간 시스템으로 넘어가는 순간을 보여주는 인간 행위자다.

## 정본 사실
- 2009-01-11 `Running bitcoin`이라는 공개 상태 메시지를 남겼다. (`F-0023`)
- 2009-01-12 Block 170의 초기 비-coinbase 전송은 공개 역사기록상 Satoshi→Hal Finney 10 BTC 시험 전송으로 알려져 있다. (`F-0022`)

## 묘사 규칙
- 공개 기록으로 확인되지 않은 심리, 사적 대화, 동기, 주변 환경을 사실처럼 단정하지 않는다.
- `Running bitcoin`은 실제 공개 기록이지만 직접 인용 범위를 불필요하게 늘리지 않는다.
- 초기 참여를 Bitcoin의 공동 창시자라는 의미로 과장하지 않는다.

## 서사 기능
Hal은 Bitcoin이 단독 설계자의 산출물에서 타인에게 전달되고 시험되는 네트워크로 이동했음을 보여준다. Bitcoin 의인화 캐릭터와 분리한다.

## 초상화 정책
실존 인물의 외모를 소설용 합성 캐릭터 아트로 재현하지 않는다. 정본 초상화 갤러리는 프로토콜·자산 의인화 인물 중심으로 유지한다.

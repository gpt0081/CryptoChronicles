# Adaptive Review Loop

Pass 5는 모든 장을 동일 비용으로 검수하지 않는다. 기본 2-review 이후 위험도에 따라 검수 깊이를 늘리는 적응형 루프를 사용한다.

## Stage A — Base Review

- 장당 2개 역할
- 서로 다른 관점 조합
- 기존 review 결과 비공개
- 결과는 inbox에만 작성

## Stage B — Triage

다음 항목으로 장의 위험도를 판정한다.

- CRITICAL: +5
- MAJOR: +3
- MINOR: +1
- 서로 다른 역할이 같은 문제를 독립 발견: +2
- 검수자 간 직접 충돌: +2
- 역사/기술 confidence=low: +1

권장 기준:

- 0~2: 기본 검수 종료 후보
- 3~5: 편집 판단 후 필요 시 1개 역할 추가
- 6 이상: 세 번째 검수 + red-team 우선

점수는 자동 진실 판정이 아니라 자원 배분용 신호다.

## Stage C — Decision

편집 루프는 findings를 다음 세 묶음으로 먼저 정리한다.

1. 사실/연속성처럼 검증 가능한 문제
2. 개연성/캐릭터처럼 작품 내부 규칙으로 판정할 문제
3. 취향/리듬처럼 편집 판단이 필요한 문제

1번을 먼저 닫은 뒤 2번, 3번 순서로 처리한다. 이렇게 해야 한 번의 수정으로 여러 지적이 사라질 가능성이 높다.

## Stage D — Minimal Fix

- ACCEPTED만 수정
- 한 커밋은 가능하면 한 장 또는 하나의 연속성 묶음에 집중
- 커밋 메시지에 review source를 기록
- 대규모 재작성은 별도 decision 없이 진행하지 않음

## Stage E — Regression

기본 회귀 범위는 `이전 장 + 수정 장 + 다음 장`이다.

다음 경우 범위를 확대한다.

- 인물의 지식/관계 변경: 해당 인물의 이후 주요 등장 장
- 역사 날짜 변경: 같은 사건을 참조하는 모든 장
- 세계관 규칙 변경: 관련 개념이 등장하는 모든 장

## 비용 절약 규칙

- NO_FINDINGS 보고서도 유효한 검수로 인정
- 같은 역할의 반복 검수는 수정 발생 후에만 허용
- MINOR/NOTE만 있는 장은 기본적으로 추가 에이전트 호출 금지
- 동일 문제를 세 번째 모델에게 다시 묻는 대신 먼저 근거를 확인
- 전체 원고 재독은 마지막 회귀 단계 전까지 금지

## 완료 정의

개별 장은 다음을 만족하면 `reviewed`다.

- 배정된 독립 검수 완료
- CRITICAL=0
- MAJOR=0 또는 명시적 DEFERRED
- ACCEPTED 수정 반영
- 필요한 회귀 검수 완료

전체 Pass 5는 48개 장이 모두 `reviewed`가 된 뒤 최종 cross-volume continuity sweep을 1회 수행하면 종료한다.
